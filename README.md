# Uber Ride Data Analysis Dashboard Using Power BI

## 📌 Project Overview
This project focuses on analyzing Uber ride booking data using Power BI to generate meaningful business insights through interactive dashboards and visualizations. The dashboard helps understand customer behavior, ride trends, revenue generation, and vehicle performance.

---

## 🚖 Key Features
- Total Booking Analysis
- Revenue & Booking Value Insights
- Trip Distance Analysis
- Pickup & Drop-off Location Analysis
- Vehicle Type Performance Analysis
- Peak Hour & Time Analysis
- Interactive Filters and Slicers
- KPI Cards and Dynamic Visualizations

---

## 📊 Dashboard Highlights

### Overview Analysis
- 103K+ Total Bookings
- $1.6M Total Booking Value
- 349K Miles Total Trip Distance
- Average Trip Time & Distance Analysis
- Payment Type Distribution
- Most Frequent Pickup & Drop-off Locations

### Time Analysis
- Hourly Trip Distance Trends
- Day-wise Booking Analysis
- Heatmap Visualization for Ride Activity
- Peak Booking Hour Detection

### Detailed Analysis
- Complete Ride-Level Information
- Trip Distance & Fare Details
- Passenger Count Analysis
- Vehicle & Payment Type Details

## 📁 Dataset Information

### Trip Details Table
The dataset contains:
- Trip ID
- Pickup Date & Time
- Drop-off Time
- Passenger Count
- Trip Distance
- Payment Type
- Fare Amount
- Surge Fee
- Vehicle Type
- Pickup & Drop-off Locations

### Location Table
Contains mapping of:
- Location ID
- Area Name
- City Information
